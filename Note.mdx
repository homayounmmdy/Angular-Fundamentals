## Creating a Component

```ts
import { Component } from "@angular/core";

@Component({
  selector: "app-root",
  standalone: true,
  template: `<h1>Hey , Frontend Masters!</h1>`,
  style: `h1 { color : red}`,
})
class AppComponent {}
```

# A tale of two systems

## Template Driven Forms

- Quick to setup and use
- Best for small one-time use forms
- Requires more configuration for testing

## Reactive Forms

- Supports typings
- Reusable , can share models
- More robust testing configuration

# Dependency Injection (DI)

is a design pattern and mechanism for creating and delivering some parts of an app to other parts of an app tha require them.
